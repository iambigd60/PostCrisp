## Exact access and authorization checkpoints

1. **Vercel/firewall and environment linkage:** the deployment ID/SHA and deployed provider paths are verified, but the refreshed connector still exposes no firewall or environment-name inventory. The bounded log attempts did not prove runtime/provider linkage. To close the gap, use an authenticated read-only surface that exposes firewall overview, expanded active rules, IP blocks, system bypasses, Attack Mode, managed rules/system mitigations, draft diff, production environment-variable **names only**, and secrets-free successful runtime/provider evidence. Do not stage or publish anything.
2. **Anthropic:** an organization Billing/Admin must expose the Claude Console Limits page, or supply a read-only Admin API route, so the audit can record the actual monthly spend cap/self-set limit and all effective organization/workspace rate limits. Do not inspect API keys.
3. **OpenAI:** an organization/project Owner must expose the project's Limits page or a read-only Admin API session so the audit can record the actual spend amount, hard/monitor enforcement, alert thresholds, enabled models, and model rate limits. Do not inspect API keys.
4. **Leaked-password protection:** the user must explicitly authorize enabling the setting. After the change, rerun the Supabase security advisor; until then it remains `NOT ENABLED`.
5. **Restore source/UI access:** an authenticated Supabase Dashboard operator must first verify that the selected completed physical backup exposes **Restore to a New Project** and record the final non-sensitive compute, disk type/size, IOPS, throughput, add-ons, one-time charges, and displayed estimate. This is observation only; stop before confirmation.
6. **Restore drill authorization:** after the fresh source preflight is safe and the conservative five-billable-hour estimate is below USD 8, the user must explicitly authorize the production-sensitive clone and accept the documented residual risk that usage/billing reporting can lag or include an unlisted charge. Until execution, validation, post-deletion billing evidence, and cleanup pass, Phase 0 remains blocked.
